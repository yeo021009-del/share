이 프로토타입에 대해

  1. 흐름시작 → 차량 선택 → 촬영 → 판정, 4화면 전부 클릭해 볼 수 있습니다.
  2. 진짜 수식판정은 목업이 아니라 실제 공식 √(2RW+(L−l₁)²)으로 계산됩니다. 차종을 바꾸면 결과가 바뀝니다.
  3. 데모 씬측정 간격은 6.30 m로 고정(사전 분석 캐시 가정) — 레이 🟢 / 아반떼 🟡 / 카니발 🔴이 한 자리에서 갈립니다.
  4. 실서비스촬영 입력은 input capture(EXIF 보존) 그대로이며, 서버 연동 시 이 파일이 프론트 뼈대가 됩니다.
